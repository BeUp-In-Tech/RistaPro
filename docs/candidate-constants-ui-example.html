Candidate Constants Frontend Reference

Use this page as the frontend handoff for rendering cascading religious and caste identity dropdowns from GET /api/v1/candidates/constants.

Implementation Plan

1. Fetch Once

  • Call GET /api/v1/candidates/constants when the profile form opens.
  • Use response.data.religionTree for religious fields.
  • Use response.data.casteTree for caste identity fields.
  • Show name in the UI and store id in form state.

2. Religious Dropdowns

  • Religion comes from religionTree.
  • Sect comes from selectedReligion.sects.
  • Details come from selectedSect.detailGroups.
  • Supported detail group IDs include madhhab, movement, orientation, and branch.

3. Caste Dropdowns

  • Category comes from casteTree.
  • Caste / Biradari / Tribe comes from selectedCategory.castes.
  • Clan / Lineage comes from selectedCaste.clans.
  • Disable child dropdowns when a parent is empty or has no children.

4. Reset Rules

  • When religion changes, clear sect and all religious detail fields.
  • When sect changes, clear all religious detail fields.
  • When caste category changes, clear caste and clan.
  • When caste changes, clear clan.

Payload To Submit

Submit keys only. The backend validates keys and resolves display labels from constants. Do not submit old flat fields like lineage, tribe, or top-level caste. 

{
  "religious": {
    "religion": "ISLAM",
    "sect": "SUNNI",
    "madhhab": "HANAFI",
    "movement": "DEOBANDI",
    "theologicalOrientation": "MATURIDI"
  },
  "casteIdentity": {
    "category": "PUNJABI",
    "caste": "JATT",
    "clan": "BAJWA"
  }
}

Frontend Logic

const state = {
  constants: null,
  religious: {},
  casteIdentity: {}
};

const fillSelect = (select, options, placeholder) => {
  select.innerHTML = "";
  select.append(new Option(placeholder, ""));
  for (const option of options || []) {
    select.append(new Option(option.name, option.id));
  }
  select.disabled = !options?.length;
};

const getReligion = () =>
  state.constants.religionTree.find((item) => item.id === state.religious.religion);

const getSect = () =>
  getReligion()?.sects?.find((item) => item.id === state.religious.sect);

const getCategory = () =>
  state.constants.casteTree.find((item) => item.id === state.casteIdentity.category);

const getCaste = () =>
  getCategory()?.castes?.find((item) => item.id === state.casteIdentity.caste);

// On religion change:
state.religious = { religion: selectedReligionId };
fillSelect(sectSelect, getReligion()?.sects || [], "Select sect");

// On category change:
state.casteIdentity = { category: selectedCategoryId };
fillSelect(casteSelect, getCategory()?.castes || [], "Select caste");

// Final create/update body:
const body = {
  religious: state.religious,
  casteIdentity: state.casteIdentity
};
